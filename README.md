# Auto Edit Trend — bản cài Windows

Chỉ chứa các bản phát hành (file `.zip`) của app Auto Edit Trend. Mã nguồn không nằm ở đây.

**Cài:** vào [Releases](../../releases/latest) → tải `AutoEditTrend-<phiên bản>.zip` → giải nén vào thư mục ngắn (vd `D:\AutoEditTrend`)
→ bấm đúp `AutoEditTrend.exe`. Không phải cài thêm gì.

**Cập nhật:** app tự báo «↑ Cập nhật» khi có bản mới; bấm là xong (dự án, giọng, cài đặt giữ nguyên).
